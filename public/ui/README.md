# รูปประกอบ UI

โฟลเดอร์นี้ใส่รูปประกอบได้หลายไฟล์ เกมจะสลับไปใช้อัตโนมัติถ้าเจอไฟล์
ไฟล์ไหนไม่มี เกมจะใช้ไอคอน SVG ที่วาดไว้ในโค้ดแทนให้เอง เล่นได้ปกติ

## `icons.png` — ตาราง 3 x 3

| ช่อง | ใช้กับ |
|---|---|
| 1 | ปุ่มทีมค้นหา + ไอคอนตำรวจบนแถบบน |
| 2 | ปุ่มทีมซ่อนแอบ + ไอคอนกล่องบนแถบบน |
| 3 | ปุ่มร้านค้า |
| 4 | ปุ่มเปลี่ยนห้อง |
| 5 | ปุ่มห้อง |
| 6 | ปุ่มตัวเลือก |
| 7 | ปุ่มกระโดด |
| 8 | ปุ่มล็อกท่า (ใช้เมื่อไม่มี `lock.png`) |
| 9 | ปุ่มต่อย |

## `icons2.png` — ตาราง 2 x 2

| ช่อง | ใช้กับ |
|---|---|
| ซ้ายบน | เหรียญทอง |
| ขวาบน | ปุ่มเปลี่ยนร่าง |
| ซ้ายล่าง | (สำรอง — หัวใจ) |
| ขวาล่าง | (สำรอง — ตราเลเวล) |

## `lock.png` — สองช่องเรียงแนวนอน (อัตราส่วน 2:1)

| ช่อง | ใช้กับ |
|---|---|
| ซ้าย | แม่กุญแจ **ล็อกอยู่** (ตอนกดล็อกท่า) |
| ขวา | แม่กุญแจ **ปลดล็อก** (สถานะปกติ) |

## `timer.png` — รูปเดี่ยว

นาฬิกาทรายข้างเวลานับถอยหลัง ทั้งบนแถบล็อบบี้และในเกม

## ข้อแนะนำ

- พื้นหลังโปร่งใส ขนาด 1024 px ขึ้นไปต่อด้าน
- วางวัตถุให้อยู่กลางช่องและเว้นขอบพอสมควร เพราะเกมครอปตามสัดส่วนช่องพอดี
- ถ้าจะเปลี่ยนลำดับช่อง แก้ที่ `public/style.css` ตรงบล็อก `.ico3d[style*="--c:N"]`, `.ico2[style*="--d:N"]` และ `.lockimg`
